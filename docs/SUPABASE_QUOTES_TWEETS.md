# إعداد جدول الأقوال والتغريدات في Supabase

1. افتح مشروع Supabase ثم انتقل إلى **SQL Editor**.
2. افتح ملف الترحيل `supabase/migrations/202609040001_create_quotes_tweets.sql` من المشروع.
3. انسخ محتوى الملف كاملًا إلى محرر SQL واضغط **Run** مرة واحدة.
4. تأكد من ظهور جدول `quotes_tweets` في **Table Editor**.
5. افتح لوحة تحكم الموقع ثم قسم **الأقوال والتغريدات** وأضف أول محتوى.

الجدول يحتوي على العنوان، النص، النبذة، القائل، النوع (`قول` أو `تغريدة`)، رابط المصدر، وتاريخ النشر. يسمح للزوار بالقراءة فقط، بينما تتم الإضافة والتعديل والحذف من لوحة التحكم عبر مفتاح الخدمة الموجود في الخادم.
